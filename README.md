Simple Calculator

A basic command-line calculator built with Python. This project demonstrates fundamental programming concepts including user input, conditional statements, and basic arithmetic operations.

Features

- Four Basic Operations: Addition, subtraction, multiplication, and division
- User Input: Interactive prompts for operators and numbers
- Error Handling: Validates operator input and handles invalid entries
- Formatted Output: Results rounded to 3 decimal places for clarity

How to Use

Run the program:
python Python\ Simple\ Calculator.py

Follow the prompts:
- Enter an operator: +, -, *, or /
- Enter the first number
- Enter the second number
- 
View your result: The calculator displays the result of your operation.
